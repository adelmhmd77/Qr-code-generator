## Overview

QR Code Generator is a small static web page. You type a piece of text or a URL into the input field, click **Generate Qr Code**, and the page displays the matching QR code image.

The QR code is not generated locally. The page requests the image from the external [QR Server API](https://goqr.me/api/) (`api.qrserver.com`).

## Features

- Single input field for text or a URL
- One-click QR code generation
- QR code displayed on the page as a 150×150 image
- No build step, framework, or package installation required

## Technologies

## Getting Started

### Prerequisites

- A modern web browser
- An internet connection (the QR code image is fetched from an external API)

### Installation

```bash
git clone https://github.com/adelmhmd77/Qr-code-generator.git
cd Qr-code-generator
```

No dependencies need to be installed.

### Usage

1. Open `index.html` in your browser.
2. Enter the text or URL you want to encode.
3. Click **Generate Qr Code**.
4. The QR code appears on the page.

## Notes

- This is a static, frontend-only project with no backend of its own.
- QR code images are generated by the third-party `api.qrserver.com` service, so the text you enter is sent to that service as part of the image request.
- The app needs an internet connection to generate QR codes.
- The QR code size is fixed at 150×150 pixels in the current code.
